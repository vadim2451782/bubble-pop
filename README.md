# Bubble Pop — Bubble Shooter PWA

**Играть: https://vadim2451782.github.io/bubble-pop/**

Мобильная игра «Bubble Shooter» на HTML5 Canvas 2D + JavaScript.
24 уровня, бустеры, монеты, звёзды, сохранение прогресса, звук и музыка.
Устанавливается на iPhone через Safari → «Поделиться» → «На экран "Домой"»,
работает офлайн после первого запуска. Без App Store, аккаунтов и платных API.

## Управление

- Проведите пальцем по полю — прицеливание, отпустите — выстрел.
- Нажмите на шарик справа от пушки, чтобы поменять текущий и следующий.
- Бустеры внизу: бомба, молния, радужный шар, ракета.

## Локальный запуск

```bash
npm run start:dist   # http://localhost:4174
```

Проект статический: содержимое этой ветки можно раздавать любым HTTPS-хостингом.
